KELP
A launcher for Minecraft: Java Edition, made by Samuel Arther.

NOT AN OFFICIAL MINECRAFT PRODUCT. NOT APPROVED BY OR ASSOCIATED WITH MOJANG OR MICROSOFT.


STARTING KELP
Kelp comes with its own Java, so there's nothing else to install.

  Windows:  double-click "Start Kelp".
            If Windows says it protected your PC, click "More info", then "Run anyway".

  Linux:    run start-kelp.sh (double-click it, or type ./start-kelp.sh in a terminal in this folder).

  Mac:      open Kelp.app. The first time, macOS will refuse because Kelp isn't from the App Store:
            open System Settings > Privacy & Security, scroll down, and click "Open Anyway" next to Kelp.
            After that it opens normally.


PLAYING
  1. Click Instances, then New Instance. Give it a name, pick a version (26.3 is the newest), and click Create.
  2. Pick it and click Play. The first time, Kelp downloads the game, which takes a minute.

  You need to own Minecraft: Java Edition to use Kelp.
  For now Kelp plays offline: single player and LAN work, but big online servers don't yet.
  Microsoft login is coming.


MODS
  Kelp has Squid, its own mod loader, built in. Pick an instance, turn Squid ON, click Mods, then Open Folder,
  and drop Squid mods in there.


PROBLEMS?
  Email kelp@kelplauncher.org and attach the kelp-output.log file from that instance's folder
  (Options... > Open Kelp Folder > instances > the instance's name).
